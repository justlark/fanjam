# FanJam

[FanJam](https://fanjam.live) is an event planning app that bridges the gap
between a single person with a spreadsheet and the kinds of people who can
afford enterprise event planning software.

This repo is updated automatically with each public release of FanJam.

Email <lark@fanjam.live> with any questions.
